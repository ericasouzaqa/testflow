# TESTFLOW

Aplicação desktop e web para executar Collections do Postman em lote usando arquivos CSV.

## Recursos

- Importação de Collections Postman v2.1
- Execução com dados CSV e variáveis de ambiente
- Renovação automática de token em respostas 401
- Histórico e exportação de resultados

## Executar localmente

```bash
npm install
npm run dev
```

Para gerar a versão web:

```bash
npm run build:web
```

Os instaladores são publicados na página **Releases**.
